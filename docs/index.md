# AI News Daily

毎日の生成AI関連ニュースを Claude Code が自動収集・要約してまとめる日本語アーカイブです。

詳細は [GitHubリポジトリ](https://github.com/kazu-dota/ai-news-daily) をご覧ください。

## 最新のサマリー

過去のサマリーは [`summaries/`](https://github.com/kazu-dota/ai-news-daily/tree/main/summaries) ディレクトリで一覧できます。

> 自動生成のインデックスは初回ルーティン実行後にここへ表示されます。

## 注意事項

本サイトの要約は、各ニュース・記事・論文の事実情報を独自に再構成したものです。
詳細・全文は必ず元記事をご参照ください。
