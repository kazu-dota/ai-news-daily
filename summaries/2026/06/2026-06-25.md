### <a id="anthropic-claude-tag"></a>Anthropic: Claude Tag — Slack に @Claude を共有 AI チームメンバーとして招待 (6/23 発表)

※ 本ニュースレター初報。6/23 に発表されたが 6/24 サマリーで未掲載だった記事の補完。

Anthropic は 6 月 23 日、**Claude Tag** を Slack 向けリサーチプレビューとして Enterprise/Team ユーザーに公開した。従来のプライベートチャット型 AI と異なり、Claude がチャンネル内に「共有 ID」として参加し、チーム全員が @Claude に作業を委任できる仕組みだ。

主な特徴:
- **共有 ID**: 同じ Claude インスタンスをチャンネル全員が利用し、半完成の作業を他のメンバーが引き継げる
- **非同期タスク実行**: @Claude に依頼すると Claude がフェーズに分解して自律実行し、Slack に結果を返信する
- **Ambient モード**: 放置されたスレッドや宿題になっているタスクを Claude が検知してプロアクティブにフォローアップする
- **ツール・データ連携**: 管理者が選択したコードベース・データソース・外部ツールと接続可能
- **モデル**: Anthropic Opus 4.8 で動作

Anthropic は内部版の同様の仕組みで「プロダクトチームが書くコードの 65% を生成している」と述べており、社内で有効性を実証した後に外部公開したかたちだ。OpenAI の Agent Chat や Microsoft Teams の Copilot エージェント機能と正面から競合するポジショニングとなる。

### <a id="xai-grok-build-goal"></a>xAI: Grok Build に `/goal` — 長時間自律タスク実行モードを追加 (6/22 発表、未掲載補完)

※ 本ニュースレター初報。6/22 に発表されたが未掲載だった記事の補完。

xAI は 6 月 22 日、コーディングエージェント環境 **Grok Build** に長時間タスク向けの新コマンド **`/goal`** を追加した。実装目標を入力すると、エージェントがアプローチを計画してチェックリスト化し、ユーザーの都度指示なしに完了と検証まで自律実行する仕組みだ。

主な仕様:
- タスクを計画 → 進捗チェックリストを生成 → 順次実行
- 検証手段: コードレビュー・ウェブページ目視・スクリプト実行
- **ステータス確認・一時停止・再開・キャンセル**の制御コマンドをサポート
- 完了条件が満たされるまでループを継続

Claude Code の Computer Use や OpenAI Codex の自律エージェントモードに対応する機能で、Grok Build が 5 月デビュー以来最大の機能強化となる。Cursor を SpaceX が買収した背景もあり、コーディング AI エコシステムの競争が加速している。

### xAI: Grok 4.3 が Amazon Bedrock に上陸 — 1M トークンコンテキスト・最安値クラスの推論モデル (6/15、未掲載補完)

※ 本ニュースレター初報。6/15 に発表されたが 403 取得不能のため未掲載だった記事の補完。

6 月 15 日、xAI の推論モデル **Grok 4.3** が Amazon Bedrock に初登場した。xAI にとって Amazon Bedrock への初の統合であり、Anthropic・OpenAI と同じマーケットプレイスに並ぶことになった。

主なスペック:
- **コンテキストウィンドウ**: 100 万トークン (最大出力 30,000 トークン)
- **推論レベル**: なし / 低 / 中 / 高 から設定可能
- **価格**: $1.25 / $2.50 (100 万入出力トークンあたり) — Bedrock 上の米国系フロンティア推論モデルとしては最安値クラス
- **実行基盤**: Amazon Bedrock 専用の新インフェレンスエンジン Mantle 上で動作
- ツール呼び出し・構造化出力・レスポンスストリーミングに対応
- 想定用途: カスタマーサポート・法務文書解析・ウェブ開発・金融 Q&A など
