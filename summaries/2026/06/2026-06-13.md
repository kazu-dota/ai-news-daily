### <a id="anthropic-dxc"></a>Anthropic × DXC: ミッションクリティカルエンタープライズへの多年グローバル同盟 (6/11)

DXC Technology と Anthropic は 6 月 11 日、多年にわたる多年グローバル同盟を発表した。DXC は Claude Partner Network の数少ない Global Premier パートナーとして認定された。

同盟の柱は、DXC が運用する金融・航空・保険・製造・政府機関向けの基幹 IT インフラに Claude を組み込むこと。具体的には**数万人規模の Claude 認定エンジニア**を育成し、DXC のグローバル顧客ベースに Claude を展開する体制を整える。すでに DXC の内部では、2026 年 4 月に公開したコード自動生成製品 DXC OASIS でコードの **95% 超を Claude が生成**し、ソフトウェア納品速度が従来比約 **10 倍**に達したという。DXC OASIS は現在 50 社超の顧客に展開されており、この実績を対外的な販売材料として活用する戦略だ。

注力分野は保険・サイバーセキュリティ・アプリケーションサービスの 3 領域。Anthropic にとっては、Claude Code の開発者コミュニティ向け浸透に続き、グローバル SI 経由でのレガシーエンタープライズへの侵入口を確保する動きと位置付けられる。

### <a id="openai-ona"></a>OpenAI: Ona (旧Gitpod) 買収 — Codex エージェントのクラウド常時稼働を実現 (6/11)

OpenAI は 6 月 11 日、ドイツ・キール発のクラウド開発環境スタートアップ **Ona (旧称 Gitpod)** の買収計画を発表した。

Ona はセキュアな隔離型クラウド実行環境を提供し、AI エージェントが開発者のデバイス電源オフ後も作業を継続できる仕組みを持つ。買収により Codex との直接統合が進み、長時間かかるコーディングジョブやコードレビューを非同期で完結させられるようになる。「ユーザーが離席している間も Codex がタスクを続けられる」という設計は、Claude Code がすでに持つ GitHub Actions 連携と同様の方向性だ。

OpenAI によれば、Codex の週間アクティブユーザーは現在 **500 万人超**で、2026 年初頭比で約 **400% 増**に達しており、エンタープライズ需要への対応能力増強が急務となっている。買収金額は非公開。取引完了後も Ona チームは独立した組織として Codex 組織と協業する形を維持する予定だ。
