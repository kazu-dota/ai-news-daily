**① Trump G7 発言 (6/21 ごろ)**

G7 サミット (エヴィアン=レ=バン) で Dario Amodei と会談した Trump 大統領は記者団に「交渉は順調だ (going fine)」と発言。ホワイトハウスは「Trump は Anthropic のモデルをめぐる国家安全保障上の懸念を軟化させた」と伝えた。ただし商務省の輸出規制指令は依然として法的に有効であり、正式撤回はされていない。

**② Anthropic、7/8 から生体認証 ID 確認を義務化 (復旧への道)**

Anthropic が 6 月 8 日ごろ公表し **7 月 8 日に有効となる**改定プライバシーポリシーで、消費者向けアカウント (Free / Pro / Max) に対して Persona Identities 社を介した本人確認を義務付ける権限を明記した。

収集情報の範囲:
- 政府発行の写真付き ID (パスポート・運転免許証・国民 ID カード等)
- ライブセルフィーによる本人確認 (ディープフェイク防止)
- 「一部地域で生体情報に相当しうる」顔の幾何学テンプレート (顔面上の特徴点間距離の数値マッピング)

Persona Identities が生データを自社サーバーで保管し、Anthropic は「確認済み / 未確認」という結果のみを保持するとしている。**Team / Enterprise / API アカウントは対象外**。

分析筋は「この仕組みで Anthropic が『接続ユーザーが米国籍であることを技術的に担保できる』と示せれば、輸出規制指令の全面撤回を待たずに Fable 5 の国内向け段階復旧が可能になる」と指摘している。利用者・プライバシー研究者からは「停止と時期を同じくした ID 強化は事後対応ではなく計画的な準備では」との疑念も上がっている。
