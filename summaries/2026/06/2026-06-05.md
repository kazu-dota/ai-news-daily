### <a id="openai-rosalind-update"></a>[続報] OpenAI: GPT-Rosalind に新機能追加 — 世界中の研究機関へ研究プレビューを初公開 (6/3)

OpenAI は 6月3日、ライフサイエンス特化の GPT-Rosalind に新機能を追加し、対象外だった全世界の適格研究機関への研究プレビュー提供を初めて開始した。主な更新点は次の 3 点。第一に、創薬・ゲノミクス・臨床研究の全ドメインで GPT-5.5 を超える性能を達成しつつ、ゲノミクスの長期定量タスクでは GPT-5.5 比 31% のトークン削減を実現した。第二に、証拠取得・生物学的解釈・バイオインフォマティクス実行を一体化した **Life Sciences Research プラグイン** および **Life Sciences NGS Analysis プラグイン** を同時公開した。第三に、従来の限定パートナー (Amgen・Moderna・Allen Institute・Thermo Fisher Scientific ら) に加え、世界中の適格研究機関が研究プレビューへ申請できるようになった。

### <a id="google-imagen-deprecation"></a>Google / Google DeepMind: Imagen 3 を 2026年6月24日に廃止 — Gemini 3 Pro Image への移行を案内

Google は Imagen 系列の画像生成モデルを 6月24日付で全廃し、Gemini ブランドへ完全統合すると案内した。後継は **Gemini 3 Pro Image (コードネーム「Nano Banana Pro」)** で、高精細・マルチターン画像生成・編集に対応し、一般用途向けには `gemini-3.1-flash-image` を推奨している。既存の `imagen-*` モデルを利用している開発者はモデル名を `gemini-*-image` 系に置き換えるだけで移行可能としており、動画ファイルをコンテキストとして渡してサムネイルやポスターを生成する video-to-image 機能も `gemini-3.1-flash-image` で利用できる。なお Gemini 3.5 Pro は依然として Vertex プレビュー段階で、GA は 6月中を目標としているが本日時点では未公開。

- 元記事: [Gemini API Release Notes](https://ai.google.dev/gemini-api/docs/changelog)
- 参考: [Google Imagen Shutdown 2026: Migration Guide](https://igly.ai/blog/google-imagen-shutdown-migration-guide-2026)
