### <a id="anthropic-managed-agents-cron"></a>Anthropic: Claude Managed Agents — Cron スケジュール実行 + Credential Vault がパブリックベータへ (6/9)

Anthropic は 6 月 9 日、Claude Platform 上の Managed Agents に **Cron スケジュール実行**と **Credential Vault (認証情報の暗号化保管)** の 2 機能をパブリックベータとして追加した。

**Cron スケジュール実行**: エージェントを曜日・時刻ベースのスケジュールに紐付け、人間の起動操作なしで自律的にタスクを完遂できる。スケジュールの一時停止・再開・アーカイブ・手動トリガーも API から制御可能。楽天グループは「週次・月次でスプレッドシートを分析しレポートやスライドを自動生成するスケジュールエージェントを複数チームで稼働させている」と導入事例を公表した。

**Credential Vault**: エージェントが外部 API・認証済みサービスへアクセスする際の認証情報をプラットフォーム側で暗号化保管し、実行時に安全に取り出す仕組み。認証情報をコードやプロンプトに直接埋め込む必要がなくなる。

両機能は Claude Platform の既存 API 料金に追加費用なしで提供される。「スケジューラ・サンドボックス・シークレット保管をマネージドで一括提供する」という設計は、エンタープライズのパイロット案件を本番稼働へ引き上げる「縁の下のプラットフォーム」として位置付けられている。

Google は 6 月 10 日、GitHub に **`google/skills`** リポジトリを公開した。AI エージェントが Google Cloud 製品を正確に操作するための「スキル」(コンテキスト・実行手順・ツール定義をひとまとめにしたパッケージ) を公式に提供するもので、`npx skills install github.com/google/skills` でエージェントへ即時インストールできる。
