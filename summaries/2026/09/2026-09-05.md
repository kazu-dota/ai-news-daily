### <a id="openai-daybreak-defenders"></a>OpenAI: Daybreak for Frontline Defenders — インフラ防衛者向け $1B 補助プログラム

9 月 4 日、OpenAI が **Daybreak for Frontline Defenders** を発表した。Astra のサイバー能力 (Preparedness Framework「Critical」評定) を、エンタープライズ予算を持たない重要インフラ防衛者に届けることを目的としたプログラムで、**OpenAI 製品に対する $1B 相当のクレジット・研修・技術支援**をパッケージとして提供する。

**対象組織**:
- 水道・廃水処理施設の運営者
- 電力グリッド運営者
- 州・地方自治体
- 地域金融機関 (コミュニティバンク)
- 非営利組織・オープンソースメンテナー

**活用シナリオ**: レガシーコードの脆弱性レビュー、不審な活動の分析、脆弱性の検出・重要度評価、修正案の生成・テストなど。当初はパイロットグループ (公共水道・公共部門) から順次開始し、6 か月以内にクレジット消化を目指す計画。

なぜ重要か: Astra の Critical 評定 (ExploitBench 100%・ゼロデイ 2 件発見) が示す強力なサイバー能力を攻撃側と同じ「重量」で防衛側にも持たせることで、AI 能力のアシンメトリーを解消しようとする試み。公共インフラを外部からの AI 攻撃から守る民間主導の補助モデルとして注目される。

- 公式: [Daybreak for Frontline Defenders: $1B to protect essential services](https://openai.com/index/daybreak-for-frontline-defenders/)

### <a id="microsoft-copilot-azure-repos"></a>Microsoft (GitHub Copilot): コードレビュー機能が Azure Repos 全顧客に対応

GitHub Copilot のコードレビュー機能が、**Azure Repos ユーザー**に開放された。これまで GitHub 上のリポジトリのみが対象だったが、Azure DevOps を使用する組織が GitHub への移行をせずに同機能を利用できるようになった。

**課金・運用**:
- レビュー 1 回ごとの従量課金 — Azure サブスクリプション経由で請求
- コスト管理画面には **48 時間後**に反映 (リアルタイム表示なし)
- すべての Azure DevOps 顧客が対象

なぜ重要か: GitHub への完全移行を必要とする企業 (金融・公共・製造業界など) にとって、Azure Repos のまま AI コードレビューを導入できる経路が開けた。Microsoft が自社 DevOps スタック全体での Copilot 展開を進める一環として、GitHub との機能格差を縮小する動き。

- 元記事: [Copilot Code Review Reaches Azure Repos, Billed Per Review with Reporting Two Days Behind — InfoQ (9/4〜5)](https://www.infoq.com/news/2026/09/copilot-code-review-azure-repos/)
