### <a id="anthropic-dev-platform"></a>Anthropic: Developer Platform 大型更新 — `ant apply` CLI・Admin API GA・Managed Agents 強化

Anthropic は `ant` CLI v1.30.0 で `ant apply` コマンドを導入した。エージェント・環境・スキル・メモリストア・デプロイメントをリポジトリ内のファイルとして宣言し、`ant apply` 実行だけで作成・更新する仕組みで、CI 上での継続的なエージェントデプロイが可能になる。コミットすべき `claude-lock.json` ロックファイルにより、チームメンバーや CI が同一リソースを更新できる。

あわせて、Claude Enterprise 向けの Admin API ユーザー管理エンドポイントがベータを脱却して正式 GA となり、`ant` CLI および Python・TypeScript・Go 等 8 言語の SDK から利用可能になった。Managed Agents にはモデルエフォート設定・ウェブフック範囲拡張・セッションシーディング・バージョンチェックが加わった。なお、Anthropic は K-12 Academy のカリキュラムを更新し、教師・指導者向けの AI 活用コース・ガイドを無償公開している。

- 元記事: [Claude Developer Platform Updates — Anthropic](https://platform.claude.com/docs/en/release-notes/overview)
- 関連: [Claude Managed Agents — Anthropic Engineering](https://www.anthropic.com/engineering/managed-agents)

### <a id="openai-agents-api"></a>OpenAI: Agents API パブリックベータ公開 — Codex を支えるインフラを全開発者に解放

OpenAI は Agents API をパブリックベータとして全開発者向けに公開した。Codex や ChatGPT Work を動かしているエージェントインフラを単一 API 呼び出しで利用できる設計で、コード実行・ファイル処理・ウェブ検索・スキル適用・サブエージェントへの委譲といった機能を組み込む。セッションあたりの実行時間は数時間単位まで対応し、自動コンテキスト管理・並列ツール呼び出しも含む。サンドボックスは OpenAI 自社ホストのほか Cloudflare・Vercel・Oracle のパートナーホストから選択できる。追加料金はなくトークン量のみで課金される。

- 元記事: [Introducing the Agents API — OpenAI](https://openai.com/index/introducing-the-agents-api/)
- 解説: [OpenAI Launches the Agents API in Public Beta — MarkTechPost](https://www.marktechpost.com/2026/09/10/openai-launches-the-agents-api-in-public-beta-putting-the-codex-harness-behind-one-api-call/)

### <a id="openai-gpt-live-1"></a>OpenAI: GPT-Live-1 Voice API — 全二重音声モデルを $0.05/分でリリース (9/10)

OpenAI は 9 月 10 日、GPT-Live-1 を API で一般提供開始した。音声の入力と出力を単一モデルで同時処理する全二重アーキテクチャで、従来の STT→LLM→TTS の連結構成と比べ割り込み処理の遅延が改善している。開発者はシステムプロンプトで口調・話速・会話スタイルを自由に設定でき、Codex や ChatGPT Work と組み合わせた音声エージェント実装に対応する。価格は音声レイヤー $0.05/分、実処理はペアリングモデルのトークン課金。

- 元記事: [GPT‑Live‑1 in the API — OpenAI](https://openai.com/index/introducing-gpt-live-1-in-the-api/)
- 解説: [OpenAI's GPT-Live-1 Arrives in the API at $0.05 Per Minute — Unite.AI](https://www.unite.ai/openais-gpt-live-1-arrives-in-the-api-at-0-05-per-minute/)

### <a id="google-gemini-windows"></a>Google / Google DeepMind: Gemini Windows 版デスクトップアプリ公開 (9/10〜11)
