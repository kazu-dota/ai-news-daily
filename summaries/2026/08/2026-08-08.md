### <a id="anthropic-inference-hooks"></a>[新] Anthropic: Enterprise 向け Inference Hooks (インライン DLP) ベータ開始 (8/5)

8 月 5 日、Anthropic は Claude Enterprise 向けに **Inference Hooks** (ベータ) を公開した。従業員のプロンプトが Claude モデルに届く前に、組織が指定したセキュリティサーバーへルーティングして allow/deny 判定を受ける仕組みで、リアルタイムの DLP (データ損失防止) を実現する。

**主な仕様**:
- Standard Webhooks 仕様に準拠した署名付きリクエストで組織のセキュリティエンドポイントを呼び出す (デフォルト 5 秒タイムアウト)
- 単一の組織レベル設定が claude.ai・Claude Code (CLI)・Claude Cowork (Web・デスクトップ) のすべてに適用
- プロンプト本文・ツール呼び出しを検査でき、機密データをモデルに見せる前にブロック可能

なぜ重要か: 生成 AI 採用の最大のブレーキであった「社内機密データが外部モデルへ漏れるリスク」を、モデル接触前の段階で組織側が制御できるようにした。CASB やデータ分類基盤と統合することで、金融・医療・法務などコンプライアンス要件の厳しい業界向けの導入障壁が下がる。

- 参照: [Anthropic Puts Inline Data Loss Prevention Inside Claude Enterprise — Unite.AI (8/5)](https://www.unite.ai/anthropic-puts-inline-data-loss-prevention-inside-claude-enterprise/)

### <a id="google-deepmind-leadership"></a>[新] Google / Google DeepMind: Demis Hassabis が CEO を退任、Jeff Dean ら 4 名が Discovery Loop を共同設立 (8/5)

8 月 5 日、Alphabet は Google DeepMind の組織を大幅に刷新した。

**経営変更**:
- **Demis Hassabis** (DeepMind 共同創業者・2010 年から CEO として率いてきた) が日常的な経営から退き、DeepMind **会長 (Chairman)** および Alphabet 初の **Chief Scientist (最高科学責任者)** に就任。引き続き Isomorphic Labs (医薬品 AI) も運営
- **Koray Kavukcuoglu** (現 CTO) が新たに **Senior Vice President** として Sundar Pichai CEO 直属で指揮を引き継ぐ

**Google 退社と Discovery Loop 設立**:
- Alphabet Chief Scientist を務めた **Jeff Dean** (Google 在籍 27 年) とシニアフェロー **Sanjay Ghemawat** が同日付けで退社。**Oriol Vinyals** と **Quoc Le** も加わり **Discovery Loop** を共同設立
- Discovery Loop は科学・工学研究を AI で自動化することに特化した独立の **公益法人 (Public Benefit Corporation)**
- Google が Discovery Loop に初期投資し、クラウドプロバイダーとしても参画
- Google 株は同日 **約 4% 下落**

なぜ重要か: Dean は Google Brain 共同設立者・TPU 設計の牽引者であり、Ghemawat とは MapReduce・BigTable・GFS など現代クラウドインフラの礎を築いた「2 人組」。DeepMind CEO 退任と重なり、Google が AI 開発を主導してきた時代の象徴的な顔がほぼ同時に現場を離れた。市場はこれを競争力の後退シグナルと読んで株価を引き下げた。

### <a id="meta-muse-spark-12"></a>[新] Meta: Muse Spark 1.2 + Muse Code — Meta 初のターミナルコーディングエージェント (8/5)

8 月 5 日、Meta Superintelligence Labs (MSL) が **Muse Code** (beta) と基盤モデル **Muse Spark 1.2** を発表した。Muse Code は Claude Code や OpenAI Codex と正面から競合する Meta 初のターミナル型コーディングエージェント。

**Muse Code の主な特徴**:
- macOS・Linux で動作するターミナルベースのコーディングエージェント (beta)
- 計画・コード執筆・結果の検証を一連で実行し、複数の永続的サブエージェントを同時に調整できる
- 大規模リポジトリでの長時間タスク (multi-file リファクタ・長期デバッグなど) を対象

**Muse Spark 1.2 の仕様**:
- コンテキストウィンドウ: **100 万トークン**
- コード生成・複雑なデバッグ・コードベース理解を改善
- **Terminal-Bench 2.1: 82.9%** — GPT-5.6 Terra in Codex (81.8%)・Grok 4.5 を上回り Claude Opus 5 (86.7%) に次ぐ第 2 位
- API 価格: キャッシュ入力 $0.15、入力 **$1.25**、出力 **$4.25** / 1M トークン
- Meta Model API・OpenRouter で利用可能

なぜ重要か: Meta は Llama による OSS 公開路線と並行して、クローズド型の高性能コーディングエージェントという「もう一つの戦線」を開いた。特に TB2.1 で GPT-5.6 Terra を抑えた点は、エージェント時代における Meta の競争力を示す初の有力エビデンス。
