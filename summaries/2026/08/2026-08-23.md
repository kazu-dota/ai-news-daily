### <a id="anthropic-agent-stack-ga"></a>[未掲載] Anthropic: computer use・browser use・Skills API・Files API が Claude Platform で一挙 GA (8/20)

8 月 20 日、Anthropic は 4 つのエージェント向け機能を同時に一般提供 (GA) した。前日までのサマリーで未掲載だったため本日初掲載。

**① computer use (GA)**:
`computer_toolset_20260801` ツールセットとして正式 GA (ベータヘッダー不要)。1 ターンで複数操作をまとめて実行する**バッチアクション**と、ズームのデフォルト有効が追加された。Claude はスクリーンショットを見ながらクリック・タイピング・スクロールを自律実行し、API を持たない既存ソフトウェアを直接操作できる。

**② browser use (新機能)**:
画面座標ではなくページの DOM 構造を読み取り、特定フィールドやボタンへの操作精度を向上。従来の computer use より少ないラウンドトリップでタスクを完結できる。

**③ Skills API**:
インストラクション・スクリプト・テンプレートを格納したフォルダを「スキル」として Claude Platform にアップロード・バージョン管理できる API。タスクに応じてスキルを動的ロードし、チームの知識をエージェントに組み込める。

**④ Files API**:
ファイルの自動期限設定、レート制限 5 倍向上、組織あたり **1 TB** のストレージを提供。

**プラットフォーム展開**:
- Skills API・Files API は **Microsoft Foundry** でも同日から利用可能
- computer use・browser use の Google Cloud Vertex AI 対応は近日予定

なぜ重要か: GA 化により「エージェントが自律的に PC 操作・ウェブ操作・スキルロード・ファイル管理」をプロダクション環境で使える条件が整った。OpenAI の Operator、Microsoft の Copilot Agents と正面から競合する基盤が完備した。

- 公式ブログ: [Build production agents with computer use, the Skills API, and the Files API](https://claude.com/blog/computer-use-skills-api-files-api)

### [未掲載] OpenAI: フロンティアモデルで Zero Data Retention (ZDR) を提供開始 (8/19)

8 月 19 日に公開された発表で、OpenAI は対象 API 顧客に対し**ゼロデータ保持 (ZDR)** と**プライベート安全処理 (Private Safety Processing)** の組み合わせを提供すると発表した。過去サマリーで未掲載のため本日記載。

**ZDR の内容**:
- リクエスト処理後、プロンプト・モデルレスポンスを OpenAI 側で保持しない
- OpenAI 担当者がコンテンツを確認することはなく、モデル学習にも使用しない

**Private Safety Processing**:
- 有害コンテンツパターンをコンテキスト横断で検出しながら、具体的な内容は OpenAI 側が参照できない設計
- 従来の「安全監視のためにデータを保持する必要がある」という制約を技術的に解消

なぜ重要か: Anthropic が「30 日間データ保持義務」を維持している ([8/21 既報](summaries/2026/08/2026-08-21.md)) のと対照的に、OpenAI がエンタープライズのデータ主権要求に先行対応した形。金融・医療・行政分野での API 採用加速が期待される。

- 公式: [Offering Zero Data Retention for frontier models — OpenAI](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)
- 報道 (Axios 8/19): [OpenAI previews zero-retention safety system as Anthropic requires data logs](https://www.axios.com/2026/08/19/openai-previews-zero-retention-safety-system-as-anthropic-requires-data-logs)
