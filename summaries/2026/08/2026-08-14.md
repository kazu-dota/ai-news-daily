### <a id="anthropic-claude-code-auto"></a>[新] Anthropic: Claude Code の auto mode が本日からデフォルトへ (8/7 告知、8/14 適用)

8 月 7 日に告知された変更が本日 (8/14 JST) から有効になった。Pro・Max・Team プランで **新しく起動する Claude Code セッションは auto mode** からスタートする。

**auto mode の仕組み**:
- ツール呼び出しごとに手動承認を求める代わりに、専用の **分類器 (classifier)** が各コマンドをレビュー
- 不可逆・破壊的・スコープ外と判定した操作を自動でブロック
- 明示的な ask ルールを設定したコマンドは従来どおり手動承認プロンプトを表示

**安全性データ**:
- 1,053 人を対象とした対照実験: 人間が危険コマンドを検出した割合 **13.6%**、auto mode 分類器は **89%**
- 従来、ユーザーは許可プロンプトの 97% を承認していたが、残り 3% の危険なケースを見落としていた

**適用範囲**:
- 今回: Pro / Max / Team プランの **新セッション** にのみ適用 (既存セッションは影響なし)
- Enterprise・API・Amazon Bedrock・Google Cloud Agent Platform・Microsoft Foundry は当面オプトイン維持 (数週間以内に同様の変更を予定)

なぜ重要か: エージェントが長時間・多ステップのタスクを実行するようになると、全コマンドへの手動確認はボトルネックになる。分類器ベースの自動審査により、安全性を高めながらエージェントの自律性を広げる実装モデルが本格的に展開される。

- 公式ドキュメント: [Choose a permission mode — Claude Code Docs](https://code.claude.com/docs/en/permission-modes)
- 解説: [Claude Code Puts Auto Mode in the Driver's Seat — The Register (8/10)](https://www.theregister.com/ai-and-ml/2026/08/10/claude-code-puts-auto-mode-in-the-drivers-seat/5285326)
- 報道: [PSA: Claude Code enabling auto mode as default next week — 9to5Mac (8/7)](https://9to5mac.com/2026/08/07/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/)
