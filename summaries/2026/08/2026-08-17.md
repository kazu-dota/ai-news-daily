### <a id="google-gemini-37-flash"></a>[未掲載] Google: Gemini 3.7 Flash — コーディング・エージェント特化 Flash モデルを公開 (8/13)

8 月 13 日、Google は Gemini の新しい Flash 系モデル **Gemini 3.7 Flash** を公開した。本サマリーへの掲載が遅れたため本日初掲載。Pixel 11 発表 (同日) と重なりニュースの陰に隠れた形だった。

**技術的改善点**:
- ゼロからの再学習をせず、アルゴリズム改善とユーザーフィードバックでモデルを全面刷新
- **DeepSWE v1.1**: 49.0% → **65.3%** (コーディング実タスク)
- **AutomationBench**: 17.0% → **30.4%** (エージェント自動化タスク)
- **WebDev Arena Elo**: 1,538 → **1,588** (Web 開発品質)

**コンテキスト・機能**:
- 入力コンテキスト: **1M トークン** (3.6 Flash と同じ)
- 最大出力: 64K トークン
- 入力: テキスト・画像・動画・音声・PDF すべて対応
- ツール呼び出し・検索・コンピュータ使用を維持

**価格**:
- イントロ価格 (〜2027/1/1): **$0.75 / $3.75 per 1M tokens** (3.6 Flash 開始時の半額)
- 標準価格 (2027/1/1〜): $1.50 / $7.50

**Gemini 3.5 Pro との関係**: Bloomberg は「Gemini 3.5 Pro が依然未発表のまま先行して Flash が出た」と報じており、Google がフラッグシップモデルより先に量産向け Flash 系を優先した格好となっている。

なぜ重要か: コーディングとエージェントのベンチマークで前世代比大幅改善を達成しつつ、価格を半額に抑えた。DeepSWE 65.3% という数値はエンタープライズが日常的なコード修正タスクをエージェントに任せることができる水準に近づいており、実用面での分岐点となりうる。

### <a id="google-imagen4-shutdown"></a>[新] Google: Imagen 4 API モデルが本日 (8/17) 廃止 — Nano Banana / gemini-3.1-flash-image へ移行を

Google は 6 月 15 日に告知していた Imagen 4 API モデルの廃止を、**本日 8 月 17 日**に実施した。

**廃止対象モデル**:
- `imagen-4.0-generate-001`
- `imagen-4.0-ultra-generate-001`
- `imagen-4.0-fast-generate-001`

**移行先**: `gemini-3.1-flash-image`（コードネーム **Nano Banana**）。`generate_images()` API の呼び出し方法が異なるため、既存コードの修正が必要。

**影響**: 本日以降、廃止対象モデルへの呼び出しは廃止警告ではなくハードエラーとなる。CI/CD パイプラインや本番環境に Imagen 4 API を組み込んでいる場合は即時対応が必要。

- 参照: [Google Imagen 4 API shutdown window: August 17 — kingy.ai](https://kingy.ai/ai-launch-tracker/google-will-shut-down-three-imagen-4-api-models-august-17/)

### <a id="xai-grok-bot"></a>[未掲載] xAI: Grok Bot beta — 常時稼働 AI エージェントチームをリリース (8/11)

8 月 11 日、xAI は **Grok Bot** のベータ版を公開した。本サマリーへの掲載が遅れたため本日初掲載。

Grok Bot は、それぞれが独自のクラウドコンピュータ (ブラウザ・ターミナル・ファイルアクセス付き) を持つ **常時稼働 AI エージェントチーム**だ。ユーザーの既存ツール・メールボックス・アプリにサインインし、マルチステップ業務を同僚のように完結させる。

**主な機能**:
- **ワークフロー学習**: 1 度デモを見せるだけでワークフローを習得し、その後は自律実行
- **エージェント間連携**: ボット同士がメッセージ・スレッド・グループチャットで情報共有しながら協調動作
- **人間介入ポイント**: 人間判断が必要と判断した際は処理を止めて承認を求める設計
- **対応プラットフォーム**: デスクトップ・iOS (Android・一般向け Grok 4.6 は近日対応予定)

**料金**:
- **SuperGrok Heavy**: $300/月 に同梱
- **Cursor Ultra**: $200/月 に同梱
- **Cursor Teams Premium**: $120/席/月 に同梱

なぜ重要か: OpenAI Operator や Claude Code に続く形で、xAI が「AI エージェントが独自の実行環境を持ち、人間のツールを操作する」製品を市場に投入した。クラウドコンピュータを各ボットに割り当てるアーキテクチャは、単一コンテキストに縛られないマルチエージェント協調を現実に近づける取り組みとして注目される。

### <a id="zai-glm53"></a>[新] Z.ai: GLM-5.3 リリース — オープンウェイト最強コーディングモデル、重みは2週間後に公開 (8/14)

8 月 14 日、Z.ai は旗艦モデルの更新版 **GLM-5.3** を公開した。

**特徴的なアプローチ**: ベースモデルの再学習なしに、スケールアップしたポストトレーニング (強化学習・SFT) だけでGLM-5.2から能力を向上させている。

**主なベンチマーク改善**:
- **Terminal-Bench 3.0**: 4.6 → **28.3**（ポストトレーニングのみで達成）
- **CyberGym 脆弱性発見**: **84.5%** (Claude Mythos 5 の 83.8%、GPT-5.6 Sol の 83.6% を上回る)
- 複雑なコーディング・長期タスクに特に強く、オープンウェイト系で現時点 SOTA と主張

**利用可否**:
- API・GLM Coding Plan (既存加入者に即日ロールアウト) で利用可能
- **オープンウェイトは未公開**: サイバー能力が予想以上に成長したことを受け、安全性評価・ハードニングを完了後 (約2週間) に公開予定

なぜ重要か: ベースモデルを変えずにポストトレーニングだけで frontier クラスの能力改善を実現した点は、訓練効率の観点で業界的な関心を集めている。一方、サイバーセキュリティ能力が「予想外に成長した」としてウェイト公開を遅らせた決断は、能力急伸モデルに対する安全評価の必要性を示すケーススタディとなる。
