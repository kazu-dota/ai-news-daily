### Anthropic: Claude Code 8/4 アップデート — background /code-review・Focus View・サンドボックス認証情報強化

8 月 4 日、Claude Code に実用性と安全性を高める複数の機能が追加された。

**主な変更点**:
- **background /code-review**: `/code-review` スラッシュコマンドがバックグラウンドサブエージェントで実行されるよう変更。レビュー処理が会話本文を埋めなくなり、スタックされた続きのコマンドを引き続きターゲットとして扱える
- **Focus View**: VS Code の chat-menu に追加できるトグル。ツール実行の詳細を折りたたみ可能な per-turn サマリーとライブ実行インジケータに集約。Ctrl+Alt+F または「Claude Code: Toggle Focus view」コマンドで切り替え
- **サンドボックス認証情報マスキング**: Linux・WSL 向けに新たな "mask" モードを追加。サンドボックス内のコマンドはセンチネルコピーを参照し、egress 時にプロキシが実値へ置換する設計で認証情報の境界を強化
- **Stats パネル強化**: キャッシュトークン (入力・出力・キャッシュ読み取り・書き込み別) を詳細表示
- **スクリーンリーダー対応**: `--ax-screen-reader` モードで単語・行単位の削除テキストを音声通知

あわせて、**Claude Sonnet 5 のプロモーション価格 ($2/$10 per Mtok 入力/出力) が 2026 年 8 月 31 日をもって終了**し、9 月 1 日より通常価格 ($3/$15 per Mtok) へ移行する。Sonnet 5 を主力ワークフローに採用している場合は月次コストが最大 50% 増加するため、事前の使用量確認が推奨される。

- 参照: [Claude Code Changelog — code.claude.com](https://code.claude.com/docs/en/changelog)
- 参照: [Claude Sonnet 5 Pricing — Anthropic](https://www.anthropic.com/news/claude-sonnet-5)

### <a id="alibaba-qwen38max"></a>[新] Alibaba: Qwen3.8-Max — 2.4T 開放重み MoE、初の Max クラスオープンソース化 (8/3)

8 月 3 日、Alibaba が **Qwen3.8-Max** を発表した。同社 Qwen ファミリーで初めて「Max クラス」をオープンソース化した試みで、重みは 8 月 10 日前後に Hugging Face・ModelScope で公開予定。API は Alibaba Cloud Model Studio・QwenWork から即日利用可能。

**アーキテクチャ**:
- 総パラメータ: **2.4 兆 (2.4T)** / 推論時アクティブ: **95B** (スパース MoE)
- コンテキスト窓: **100 万トークン** (デフォルト出力 65,536、最大 131,072)
- 対応入力: テキスト・画像 (マルチモーダル)

**主要ベンチマーク**:
- Terminal-Bench 2.1: **86.6** (GPT-5.6 Sol max 88.8・Claude Fable 5 84.6)
- IFBench: **82.8** (GPT-5.6 Sol 72.7・Fable 5 63.5)
- Frontend Code Arena: 4 位 (1,668 点、Claude Opus 5 比 -37 点)
- Vision Arena: **2 位** / Text Arena: **5 位**

**なぜ重要か**: Kimi K3 公開 ([7/27 既報](summaries/2026/07/2026-07-27.md)) から 1 週間余りで Alibaba が Max クラスのオープン化を宣言。今年前半にクローズドとしていた主力モデルを開放に転じる戦略回帰であり、IFBench などの命令追従ベンチでは GPT-5.6 Sol を上回る数値を示した。中国 AI 勢による大型オープンウェイト投入の波がデプロイコストとサプライチェーンの選択肢を広げ続けている。
