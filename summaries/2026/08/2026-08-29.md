### <a id="anthropic-pentagon"></a>Anthropic: Pentagon の「サプライチェーンリスク」指定に連邦地裁が違法判決

カリフォルニア連邦地裁の Rita Lin 判事が 8 月 27 日夜に下した判決で、国防総省 (DOD) が Anthropic を「サプライチェーンリスク」に指定した行為は **「修正第 1 条に基づく違法な報復」** であり、修正第 5 条が義務付ける事前告知手続きも踏まれていなかったとして指定取り消しを命じた。

DOD は 2026 年 3 月、自律兵器・国内大規模監視への Claude 使用を認めないという Anthropic の安全条件をめぐる交渉決裂の直後に同社をリスク指定した。判決文では「国防総省は Anthropic を見せしめにする意図でこの指定を行った」と明示されている。Anthropic がワシントン D.C. で継続中の別訴訟が決着するまで技術的にはリスク指定が維持されるが、今回の勝訴により事業への実質的な悪影響は軽減された。

### <a id="anthropic-claude-code"></a>Anthropic: Claude Code v2.1.x — 制限モード・セッション間メッセージング等を追加

8 月 27 日リリースの Claude Code v2.1.250 を含む一連のアップデートで主要機能が追加された:

- **Restricted Mode** (`--restricted` / `CLAUDE_CODE_RESTRICTED=1`): シェルコマンド実行・WebFetch などの強力なツールを無効化し、ファイル操作を作業ディレクトリ内に限定する安全モード。CI/CD や信頼性の低い環境での利用向け
- **セッション間メッセージング** (`SendMessage` / `ListAgents`): 同一マシン上の複数 Claude Code セッションが直接通信可能。Bedrock・Vertex・Foundry でも対応。サブエージェントから別セッションに送ったメッセージへの返信が親セッションに届く仕組みを明確化
- **Enterprise 向け利用クレジット** + サーバー管理設定の診断改善

- 参照: [Claude Code Cross-Session Messaging Guide — explainx.ai](https://www.explainx.ai/blog/claude-code-cross-session-messaging-list-agents-2026)
- リリースノート: [Claude Code v2.1.250 (Aug 27, 2026) — Havoptic](https://www.havoptic.com/tools/claude-code)
