### <a id="anthropic-haiku-55"></a>Anthropic: Claude Haiku 5.5 発表

Anthropic は「これまでで最も安価・高速・高性能な小型モデル」と説明する Claude Haiku 5.5 を公開した。Haiku 4.5 比で平均 75% 程度のコスト削減を達成し、入力 $0.10/M トークン・出力 $0.50/M トークン (プロンプト 10 万トークン以下) の価格設定となった。Haiku クラスとして初めてエフォート設定 (Low / Med / High / Xhigh / Max) に対応し、コストと精度のトレードオフを柔軟に調整できる。OSWorld 2.1 では 72.4%、Humanity's Last Exam では 45.9% を記録した。Asana が移行後 30% 超のレイテンシ改善、HubSpot が独自 CRM 評価で 92.8% の平均スコアを達成。なお Sonnet 5.5 のキャッシュ読み取り価格も同日に半額 ($0.10/M) に引き下げられ、Max/Team プランには月次 API クレジット (Max 5x: $100、Max 20x: $200、Team: 最大 $500 プール) が新設された。AWS・Google Cloud・Microsoft Azure で即時利用可能。

- 元記事: [Introducing Claude Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5)

### <a id="msft-agent-lightning"></a>Microsoft Research: Agent Lightning v1.0 — 実ハーネスで RL 訓練する 3,500 行フレームワーク

Microsoft Research Asia が Agent Lightning v1.0 を公開した。実際のデプロイハーネス (mini-SWE-agent、OpenHands 等) をそのまま強化学習のロールアウトに参加させる「Harnessed Agentic RL」設計が特徴で、ハーネスのコードを変更せず OpenAI 互換プロキシ経由でプロンプトとログ確率を記録する。Kubernetes ネイティブで動作し、ロールアウトとモデル更新を同一 GPU 上で並行処理する「Collocated Async RL」によって同期型 RL 比約 2 倍のスループットを達成。SWE-smith データセット約 6,000 件で Qwen3.5-9B を訓練した結果、SWE-bench Verified Pass@1 が 41.8% → 56.4% (+14.6 pp) に改善したと報告している。

- 元記事: [Agent Lightning v1.0](https://www.microsoft.com/en-us/research/blog/agent-lightning-v1-0-a-3500-line-lightweight-agentic-rl-framework-for-training-agents-with-real-harnesses/)
