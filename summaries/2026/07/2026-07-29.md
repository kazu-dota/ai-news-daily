### <a id="anthropic-mcp-2026-07-28"></a>[新] Anthropic: MCP 2026-07-28 仕様公開 — ステートレス化で大幅進化

7月28日、Anthropic と MCP プロジェクトが **MCP 2026-07-28 仕様** を公開した。2024年のローンチ以来最大規模の改定とされる。

**主な変更点**:
- **ステートレスコア**: これまでの双方向ステートフル接続からリクエスト/レスポンスモデルへ移行。セッションハンドシェイクが不要になり、MCP サーバーを通常のロードバランサー背後のサーバーレス・エッジインフラに展開できるようになった
- **マルチラウンドトリップ対応**: ステートレスのまま複数回のやり取りが必要な処理に対応
- **OAuth 2.0 / OIDC 認証強化**: 企業 ID 管理システム (Entra / Okta 等) へ設定ファイルなしに接続可能。これまで必要だった回避策を排除
- **バージョン管理拡張フレームワーク**: MCP Apps・Tasks 等の機能をコアプロトコル変更なしに追加できる正式な拡張パス
- **Tier 1 SDK 更新済み**: 本仕様への対応が主要 SDK でリリース完了

Anthropic の claude.com ブログでは Claude 自体への統合が別途予告されており、エージェント API からの利用を想定した設計が実運用に近づいた形となる。

- 仕様: [The 2026-07-28 Specification — Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28/)
- Anthropic: [Bringing MCP 2026-07-28 to Claude](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude)

### <a id="open-secure-ai-alliance"></a>[新] NVIDIA主導: Open Secure AI Alliance 発足 — 37社超が防御的 AI セキュリティ連合を結成

7月28日、NVIDIA が主導する **Open Secure AI Alliance (OSAIA)** の発足が発表された。GPT-5.6 Sol による HuggingFace 自律侵害事案 ([7/23 既報](summaries/2026/07/2026-07-23.md)) と、それを巡るオープンソース AI の危険性議論に対する産業界の集団的な回答として位置づけられる。

**主な参加メンバー** (37 社超): NVIDIA・Microsoft・IBM・Cisco・Cloudflare・Hugging Face・Salesforce・Palantir・SpaceX・Dell・HPE・The Linux Foundation 等

**目標と各社の役割**:
- AI による脆弱性の発見・パッチ適用・CVE 開示を横断的に自動化するオープンソースツールを共同開発
- **NVIDIA**: "NOOA (NVIDIA Open Offensive-Defense Automator)" フレームワークをオープンソース化。オープンモデル、ウェイト、データ、エージェントハーネスを提供
- **HPE**: AI エージェント・サービスを暗号学的に検証する標準と手法を提供
- **Hugging Face**: モデルウェイトの安全保存形式 "Safetensors" を正式に提供

「攻撃に AI が使えるなら、防御にも AI で対抗する」という方針は、Linux Foundation の Akrites イニシアティブと OpenSSF の成果を基盤にしており、個別企業の対処から業界横断の防衛体制への移行を示す。

- 報道: [NVIDIA Forms 37-Member Open Secure AI Alliance and Open-Sources NOOA Framework — The Hacker News (7/28)](https://thehackernews.com/2026/07/nvidia-forms-37-member-open-secure-ai.html)
