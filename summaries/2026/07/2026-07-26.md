### <a id="anthropic-opus5-community"></a>[続報] Anthropic: Claude Opus 5 — コミュニティ評価で effort toggle・追加ベンチ確認

7月25〜26日、独立した評価機関・コミュニティが Claude Opus 5 の追加評価結果と実装詳細を公表した。

**新たに確認された追加ベンチマーク**:
- **OSWorld 2.0** (コンピュータ操作エージェント): **70.6%** — エージェントが実際の GUI を操作して課題をこなす能力を評価
- **AutomationBench** (反復業務自動化): **26.0%**

**effort toggle の詳細**:
API リクエスト単位で `low` / `medium` / `high` の3段階から "thinking budget" を選択できる設計が明らかになった。単純なタスクにはコストを抑えた low を、複雑な推論タスクには high を指定することで、1リクエストごとに性能とコストのバランスを調整できる。Opus 4.8 と API 価格が同一 ($5 入力 / $25 出力 per Mtok) であるため、全ベンチマークで Opus 4.8 を上回る Opus 5 への移行は実質的にコスト変動なしで性能向上が実現できると評価されている。
