### <a id="anthropic-fable5-final"></a>[続報] Anthropic: Fable 5 含算アクセス本日終了 — 7/20 からプラン別の新構造に移行

7 月 18 日、Anthropic は **Fable 5 の含算アクセス体系を恒久的に確定**した。本日 7 月 19 日 23:59:59 PT が現行の「全プラン向け 50% 含算プロモーション」の最終期限となる。

**7/20 以降の新プラン構造**:
- **Max / Team Premium サブスクライバー**: Fable 5 が週次利用上限の 50% の範囲で **永続的に含算**される (追加課金なし)。「サブスクリプション含算への再統合」という約束が Max / Team Premium に対して履行された形
- **Pro / Team Standard サブスクライバー**: 一回限りの **$100 使用クレジット** が付与された後、$10 入力 / $50 出力 (per Mtok) の API 課金のみへ移行する。クレジット枯渇後は API 利用か上位プランへのアップグレードが必要
- **無料プラン / API 利用者**: 対象外。引き続き API 課金 ($10/$50 per Mtok) のみ

今回の措置は、Fable 5 の含算アクセスをめぐる「7/7 → 7/12 → 7/13 → 7/19」と続いた 4 度の延長・変更に終止符を打つもの。Max / Team Premium への「永続含算」はプレミアムプラン加入者への明確な価値提示となる一方、Pro ユーザーには事実上の機能削減となり、サブスク体系のグレード分化がいっそう鮮明になった。
