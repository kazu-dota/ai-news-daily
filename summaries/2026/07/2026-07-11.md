### <a id="openai-gpt-live"></a>[補完] OpenAI: GPT-Live フルデュプレックス音声モデル公開 (7/8 発表・補完掲載)

7 月 8 日、OpenAI は ChatGPT Voice の次世代モデルとして **GPT-Live-1** と **GPT-Live-1 mini** を発表した。7/8〜7/10 のサマリーでは GPT-5.6 GA・Grok 4.5 パブリックローンチ・Mistral 3 ローンチへの対応に集中したため本日補完掲載する。

GPT-Live はフルデュプレックスアーキテクチャを採用し、従来の「話す→聞く」逐次処理から脱却して **送受信を同時に処理** する設計に刷新された。モデルは毎秒数回の判断サイクルで「発話する」「待つ」「聞く」「ツール呼び出し」を状況に応じて切り替え、"mhmm" や "yeah" といった自然なあいづちも挿入する。

**主なポイント**:
- **GPT-Live-1**: 有料プラン (Go・Plus・Pro) の ChatGPT Voice デフォルトモデルへ
- **GPT-Live-1 mini**: 無料ユーザー向けデフォルトモデル
- **バックエンド**: ウェブ検索・深い推論が必要なタスクは GPT-5.5 に委譲し、応答を音声会話へ戻す
- **ユーザー評価**: 旧 Advanced Voice Mode 比の社内支持率は GPT-Live-1 が 75.7%、mini が 69.2%
- **展開**: iOS・Android・Web 全プラットフォームでグローバルロールアウト開始

### <a id="openai-chatgpt-work"></a>[補完] OpenAI: ChatGPT Work エージェント + Codex 統合デスクトップアプリ (7/9 発表・補完掲載)

7 月 9 日の GPT-5.6 GA 発表 ([7/9 既報](summaries/2026/07/2026-07-09.md)) と同日、OpenAI は **ChatGPT Work** と **Codex 統合デスクトップアプリ**を発表した。7/9 サマリーでは GPT-5.6 の内容に集中したため本日補完掲載する。

**ChatGPT Work**:
アウトカム指定型のエージェントで、接続済みアプリとファイルを横断しながら調査・分析・文書作成を実行する。完成物として文書・スプレッドシート・プレゼン・レポート・インタラクティブ Web アプリを出力する設計。スケジュールタスク機能で定期実行・変化検知にも対応し、バックグラウンドでデバイスをまたいで稼働できる。

**Codex 統合デスクトップアプリ**:
従来の Codex デスクトップと ChatGPT デスクトップが1つのアプリに統合された。Mac・Windows で Chat / Work / Codex の 3 タブを全プラン (Free 含む) で利用可能に。Codex は diff インライン編集・Pull Request レビューをサイドパネルで実行できる新機能を追加し、複数リポジトリを1プロジェクトとして扱えるようになった。

### <a id="meta-muse-spark-11"></a>[補完] Meta: Muse Spark 1.1 + Meta Model API 公開 — Meta 初の有料 AI モデル (7/9 発表・補完掲載)

7 月 9 日、Meta は **Muse Spark 1.1** と **Meta Model API** の公開プレビューを発表した。7/9 サマリーでは「Meta: 本日アップデートなし」と記載したが Muse Spark 1.1 の発表を取得できていなかったため本日補完掲載する。

Muse Spark 1.1 は Meta Superintelligence Labs が開発した **2 番目のモデル** (Muse Image に続く) で、テキスト・画像・コードを統合したマルチモーダル推論モデルとしてエージェントタスクに特化している。Muse Image が画像生成に特化するのとは対照的に、コーディング・ツール使用・コンピュータ操作での用途を主戦場としている。

**主なスペック**:
- **コンテキスト**: 1M トークン、コンテキスト長を自律的に管理する設計
- **エージェント**: プライマリエージェントとサブエージェント両方として機能するよう構築。MCP サーバーとカスタムスキルをネイティブ統合
- **コンピュータ使用**: PC・Web ブラウザの直接操作に対応
- **料金**: 入力 $1.25 / 出力 $4.25 (per Mtok) — Zuckerberg が「競合大手の **約 4 分の 1**」と強調
- **戦略的転換**: Llama オープンウェイト路線を維持しながら Muse Spark では初めて有料 API を導入。Meta が商業 AI API 市場に本格参入した転換点
- **展開**: 米国の開発者向け公開プレビューとして開始、新規 API アカウントに $20 の無料クレジット付与
