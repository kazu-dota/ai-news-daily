**Nano Banana 2 Lite (Gemini 3.1 Flash-Lite Image)**
- Nano Banana ファミリー最速・最低コストの画像生成モデル
- 生成速度約4秒、$0.034/1024×1024 画像
- テキストから画像生成 + 既存画像の編集に対応
- Gemini API・Google AI Studio・Gemini Enterprise Agent Platform で即日利用可能

**Gemini Omni Flash (公開プレビュー)**
- Gemini の世界知識を基盤にした動画生成・編集モデル
- $0.10/秒 の動画出力
- 自然言語による「キャラクター入れ替え・ライティング変更・アングル調整」などの会話型編集が可能
- オーディオ・映像トラックをネイティブに保持したまま編集
- AI Mode 検索・Gemini アプリ・NotebookLM・Google フォト・Google 広告などへのコンシューマー展開も順次予定

2つのモデルを組み合わせると「安価に画像を生成 → そのまま動画化」というコスト効率の高いクリエイティブパイプラインが成立する。

### <a id="xai-voice-agent-builder"></a>[補完] xAI: Grok Voice Agent Builder ベータ公開 (7/1 発表)

7 月 1 日、xAI は **Grok Voice Agent Builder** のベータを公開した。7/1・7/2 のルーティンでは確認できていなかったため本日補完掲載する。

ノーコードプラットフォームで、テキストで会話フローを記述するだけで本番運用可能な音声 AI エージェントを約2分で構築できる。

主な仕様:
- **アーキテクチャ**: 音声認識・LLM・音声合成を従来の3サービス接続から1つの speech-to-speech モデルに統合 → サブ秒レイテンシを実現
- **価格**: $0.05/分 (ボイス込み)
- **言語**: 25+ 言語・会話中の言語切り替えにも対応
- **ボイス**: 80+ ボイス + 2分の音声サンプルからのクローン
- **統合機能**: テレフォニー・知識検索・ツール呼び出し・ガードレール・MCP・可観測性が同梱
- **ベンチマーク**: Big Bench Audio で首位と主張

音声エージェント構築では通常 STT・LLM・TTS の3ベンダーを個別にオーケストレーションする必要があり、これを1プラットフォームに統合した点が競合との差別化ポイント。

- 公式: [Introducing the Voice Agent Builder — xAI (7/1)](https://x.ai/news/grok-voice-agent-builder)
- 解説: [xAI launches Voice Agent Builder in beta with aggressive per-minute pricing — CryptoBriefing (7/1)](https://cryptobriefing.com/xai-voice-agent-builder-beta-pricing/)

### <a id="agents-a1"></a>Agents-A1 — 35B MoE で兆パラメータ級エージェント性能 (arXiv:2606.30616)

InternScience (Shanghai AI Lab 系) が発表した **Agents-A1** は、35B の Mixture-of-Experts 構成でありながら兆パラメータ規模のエージェントと同等の性能を達成したとする論文 (HF Papers で注目)。

- **論文タイトル**: "Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent"
- **訓練手法**: (1) SFT → (2) ドメイン別教師モデル → (3) マルチ教師蒸留の3段階で、完全なエージェント軌跡 (ツール呼び出し → 観測 → 修正ループ) を学習
- **ベンチマーク**: SEAL-0 56.4 / FrontierScience-Research 40.0 / IFBench 80.6 でいずれも SOTA を主張
- **特徴**: 従来の同規模モデルが 4〜5 回のツール呼び出しで劣化するのに対し、15 回超のツール連鎖を維持する "水平スケーリング" が主眼
- **ライセンス**: Apache 2.0 (重みも HF で公開)

- [arXiv:2606.30616](https://arxiv.org/abs/2606.30616) / [HF Papers](https://huggingface.co/papers/2606.30616) / [モデル](https://huggingface.co/InternScience/Agents-A1)
