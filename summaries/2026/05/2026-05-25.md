### <a id="anthropic-glasswing-results"></a>Anthropic: Project Glasswing — Claude Mythos Preview が 10,000件超の重大脆弱性を検出、Mythos-1 が Claude Code・Claude Security に近く展開 (May 22-24)

Anthropic は 5月22日に Project Glasswing の 1 ヶ月後の経過報告を発表した。Claude Mythos Preview (一般未公開のフロンティアモデル) を約 50 のパートナー組織が防御的なセキュリティワークフローで活用した結果、インターネット上で広く使われるソフトウェアに存在する高深刻度・重大レベルの脆弱性が 10,000件を超えて特定された。

主な内訳は次のとおり。Cloudflare が報告した脆弱性は 2,000件で、うち 400件が高深刻度以上。Mozilla は Firefox 150 で 271件の修正を完了。Anthropic 自身が実施した 1,000以上のオープンソースプロジェクトのスキャンでは、現在のトゥルーポジティブ率で換算すると約 3,900件が高深刻度・重大レベルに達すると見込まれている。

Glasswing のパートナー群には AWS・Apple・Broadcom・Cisco・CrowdStrike・Google・JPMorgan Chase・Linux Foundation・Microsoft・NVIDIA・Palo Alto Networks などが含まれ、Anthropic はパートナー向けにモデルクレジット 1億ドル相当の供与と、Linux Foundation・OpenSSF・Apache Software Foundation への計 400 万ドルの寄付も合わせて発表した。

5月23〜24日には、Claude Code のソースコードに `claude-mythos-1-preview` の識別子が確認され、Mythos-1 を Claude Code および新設の Claude Security スイートに統合する準備が進んでいることが明らかになった。一方 Anthropic は「Mythos クラスのモデルを汎用公開できる水準の安全策はまだどの企業も持ち合わせていない」とも明言しており、一般提供は安全策が整うまで行わない方針を維持している。
