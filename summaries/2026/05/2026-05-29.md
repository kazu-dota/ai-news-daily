### <a id="anthropic-opus-48"></a>Anthropic: Claude Opus 4.8 を正式リリース — 推論・数学・長文理解で前世代を大幅に更新 (May 28)

Anthropic は 2026年5月28日、フラッグシップモデル **Claude Opus 4.8** を全リージョン向けに一般公開した。価格は Opus 4.7 と同じ (入力 $5/出力 $25 per M tokens) を維持しながら、複数のベンチマークで顕著な向上を記録している。

主なスコア変化は以下のとおり。数学競技オリンピック相当の **USAMO 2026** で 69.3% → **96.7%** (+27.4 pt) と最も目立つ跳躍を遂げた。コーディング評価 **SWE-bench Pro** は 64.3% → 69.2%、同 Verified は 87.6% → 88.6% に向上した。100 万トークン長文理解の **GraphWalks F1** では 40.3% → 68.1% と大幅に改善し、長大なコードベースへの対応力が強化されている。

新機能として **Dynamic Workflows (研究プレビュー)** が追加された。Claude Code 上で数十〜数百の並列サブエージェントを走らせてコードベース全体の大規模マイグレーションを実行できる機能で、既存テストスイートを品質基準としながらキックオフからマージまでを自律的に進められる。また、モデルに投入する処理「努力量」を段階的に調整できる **Effort コントロールパネル** も搭載し、コスト最適化の余地を広げた。Fast mode は前モデル比で **3 倍安価** になり、速度重視タスクへの活用が広がる。

誠実性の面では、重要な進捗を使用者に伝えない割合が 3.7%、誤った結果を無批判に報告するスコアは **0%** (シリーズ初) を達成し、過信傾向も Opus 4.7 比で 10 分の 1 以下に低下した。

### <a id="microsoft-m365-copilot-new-design"></a>Microsoft: Microsoft 365 Copilot の UI を全面刷新 — タスク認識型ワークスペースを導入 (May 28)

Microsoft は 2026年5月28日、**Microsoft 365 Copilot の新デザイン**を公式ブログで発表した。従来の静的テキスト入力欄を、作業文脈に応じてツールや提案を動的に表示する「タスク認識型ワークスペース」へと再設計するもので、Microsoft 365 アプリ全体で一貫した単一エントリポイントとして機能する。

Word・PowerPoint では、文書の内容に即したコンテキスト提案を Copilot が積極的に提示するよう改善が加えられた。ユーザー制御の面では、AI の介入範囲を特定ドキュメントセクションに制限できる「ロック」機能や読み取り専用モードが追加されている。Microsoft は本変更を「Copilot を独立ツールではなく、仕事の流れの中で連動するシステムにする」取り組みの一環として位置付けている。

- 元記事: [Introducing a new design for Microsoft 365 Copilot — Microsoft 365 Blog](https://www.microsoft.com/en-us/microsoft-365/blog/2026/05/28/introducing-a-new-design-for-microsoft-365-copilot/)
