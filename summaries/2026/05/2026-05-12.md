### <a id="anthropic-glasswing"></a>Anthropic: Project Glasswing と Claude Mythos Preview を始動

Anthropic が次世代モデル **Claude Mythos Preview** を活用したサイバーセキュリティ強化イニシアチブ「**Project Glasswing**」を発表した。Mythos Preview は汎用モデルでありながらコンピュータセキュリティ分野で際立った能力を示し、全主要 OS・ブラウザに存在する数千のゼロデイ脆弱性を完全自律で発見した。FreeBSD の17年来の遠隔コード実行脆弱性 (CVE-2026-4747) を特定・実証することにも成功している。ローンチパートナーは Amazon Web Services・Apple・Broadcom・Cisco・CrowdStrike・Google・JPMorgan Chase・Linux Foundation・Microsoft・NVIDIA・Palo Alto Networks の11組織。同モデルはセキュリティ目的での限定公開にとどめる方針で、一般 API 提供の予定はない。将来的には Mythos 級モデルを安全に大規模展開できる基盤整備を進めるとしている。

- 元記事: [Project Glasswing: Securing critical software for the AI era](https://www.anthropic.com/glasswing) (Anthropic)
- 参考: [Anthropic is giving some firms early access to Claude Mythos to bolster cybersecurity defenses](https://fortune.com/2026/04/07/anthropic-claude-mythos-model-project-glasswing-cybersecurity/) (Fortune)
- 参考: [On Anthropic's Mythos Preview and Project Glasswing](https://www.schneier.com/blog/archives/2026/04/on-anthropics-mythos-preview-and-project-glasswing.html) (Schneier on Security)

### <a id="anthropic-claude-security"></a>Anthropic: Claude Security — エンタープライズ向けパブリックベータ公開 (Apr 30〜May 4)

Claude Opus 4.7 を搭載したコード脆弱性スキャン・修正支援製品 **Claude Security** が Claude Enterprise 顧客向けパブリックベータに移行した。2月のリサーチプレビュー (Claude Code Security) から大幅に機能拡充し、リポジトリ内の特定ディレクトリを狙った標的スキャン、発見内容の CSV・Markdown エクスポート、Jira・Slack へのウェブフック送信などが追加されている。テクノロジーパートナーとして CrowdStrike・Microsoft Security・Palo Alto Networks・SentinelOne・TrendAI・Wiz の6社がツールへの統合を、サービスパートナーとして Accenture・BCG・Deloitte・Infosys・PwC が企業導入支援を提供する。Claude Team・Max 顧客への開放も近日予定。

- 元記事: [Claude Security enters public beta with Opus 4.7 vulnerability scanning and patching](https://www.helpnetsecurity.com/2026/05/04/anthropic-claude-security-public-beta/) (Help Net Security, May 4)
- 元記事: [Anthropic announces Claude Security public beta to find and fix software vulnerabilities](https://siliconangle.com/2026/04/30/anthropic-announces-claude-security-public-beta-find-fix-software-vulnerabilities/) (SiliconANGLE, Apr 30)
