### <a id="anthropic-openclaw-reversal"></a>Anthropic: OpenClaw/サードパーティエージェント規制を撤廃 — Agent SDK クレジット制で再許可 (May 13)

Anthropic が4月初旬に実施した「Claude 有料サブスクリプションでのサードパーティエージェント利用禁止」ポリシーを約6週間で大幅に緩和した。4月4日の禁止措置は、OpenClaw 等のツールが Anthropic のキャッシュ機構を迂回してサブスクリプションの何十倍ものトークンを消費するため「コスト的に持続不能」とした判断だったが、開発者コミュニティからの強い反発を受けて新設計で巻き返した。

新設された「Agent SDK クレジット」は、サブスクリプションに追加される専用クレジット枠で、OpenClaw・GitHub Actions・Telegram 経由のエージェントなど非対話型のプログラマティック利用にのみ消費される。各プランの月額 Agent SDK クレジット枠: Pro $20、Max 5X $100、Max 20X $200 (いずれも月末リセット・繰り越し不可)。枠を超えた場合は API レートで従量課金 ("extra usage" をオプトインした場合のみ)。Claude Code を CLI で対話的に使う場合やブラウザで Claude.ai を使う場合は従来の標準サブスクリプション制限から消費されるため、影響を受けない。6月15日から新請求体制が正式発効する。

### <a id="google-io-2026-day1"></a>[続報] Google / Google DeepMind: Google I/O 2026 本日開幕 — キーノートは PT 10:00 (JST 翌 02:00) (May 19 PT)

昨日「前夜」として取り上げた Google I/O 2026 が本日5月19日 (PT) に正式開幕する。Shoreline Amphitheatre (マウンテンビュー) で2日間開催され、メインキーノートは PT 10:00 (JST 5月20日 02:00) から YouTube・io.google でライブ配信される。Google 自身が「AI が会議の中心」と確認しており、開発者向けキーノートは PT 13:00 に続く。

今回のキーノートで業界が注目する主要発表候補:

- **Gemini 新モデル (Omni)**: Gemini アプリ内部から事前にリークされた UI 文字列が示す、テキスト・画像・動画を単一パイプラインで扱う統合マルチモーダルモデル「Gemini Omni」の正式発表。Google のリリースサイクルからは Gemini 3.5 が最有力で、「OpenAI GPT-5.5 と同水準、Claude Mythos には届かない」との業界評価が多い。
- **Android XR グラス**: Warby Parker・Gentle Monster と共同開発した2モデル (ディスプレイなし版・レンズ内ディスプレイ版) の正式プレビュー。Gemini 2.5 Pro によるリアルタイム翻訳・ナビ対応が確認済み。
- **Aluminium OS / Googlebook**: Android と ChromeOS を統合した新 OS で Acer・ASUS・Dell・HP・Lenovo からのパートナー製品が今秋発売予定。
- **Project Astra 最新版**: ユニバーサル AI アシスタント研究プロトタイプの新進捗が期待される。
- **Veo 更新 (内部コード "Toucan")**: テキスト→動画生成モデルの次世代版。

キーノート終了後に確認できた主要発表は翌日 (5月20日) のサマリーで詳報する予定。
