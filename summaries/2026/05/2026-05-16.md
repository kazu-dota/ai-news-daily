### <a id="microsoft-mdash"></a>Microsoft (Security): MDASH — AI主導で Windows 16脆弱性を先行発見 (May 12 発表)

Microsoft の自律コードセキュリティチームが開発した **MDASH (Multi-model Dynamic Agentic Security Harness)** が、5月 Patch Tuesday で修正された Windows の16脆弱性を人間の研究者より先にすべて検出した。4件はクリティカルなリモートコード実行 (RCE) で、Windows カーネル TCP/IP スタックや IKEv2 サービスに存在していた。10件がカーネルモード脆弱性、大半が認証なし・ネットワーク越しに悪用可能なもの。

MDASH は 100 以上の特化型 AI エージェントを協調稼働させるモデル非依存のハーネスで、脆弱性の発見・論証・エクスプロイト実証をエンドツーエンドで自動化する設計。5年分の確認済み MSRC 脆弱性に対して **96% リコール**を達成し、CyberGym ベンチマーク **88.45%** で公開リーダーボード首位に立つ。Anthropic の Project Glasswing (5/12 記載済み) と並んで、AI による自律的脆弱性発見が実用段階に入ったことを示す事例として位置づけられる。

- 元記事: [Defense at AI speed: Microsoft's new multi-model agentic security system tops leading industry benchmark](https://www.microsoft.com/en-us/security/blog/2026/05/12/defense-at-ai-speed-microsofts-new-multi-model-agentic-security-system-tops-leading-industry-benchmark/) (Microsoft Security Blog, May 12)
