### <a id="anthropic-pwc"></a>Anthropic: PwC との戦略提携を大幅拡大 — 30,000名 Claude 認定・Claude ネイティブ金融事業部門を新設 (May 14-15)

Anthropic と PwC が戦略提携の大規模な拡充を発表した。米国チームを皮切りに全世界 36.4 万人以上の従業員へと段階的に展開する計画で、まず 30,000名の PwC プロフェッショナルを Claude の認定プログラムで訓練する。共同 Center of Excellence も新設される。

拡充の重点は3領域に絞られる。①**エンジニアリングチームが Claude Code を使って本番ソフトウェアを数四半期ではなく数週間で出荷する**「エージェント型技術構築」、②エンドツーエンドで取引をエージェントが支援する「AI ネイティブ型ディール実行」、③金融・サプライチェーン・HR・エンジニアリング機能をスケーラブルな AI ネイティブ運営モデルへ転換する「企業機能の抜本改革」。PwC は Claude 専用の金融事業グループを新設し、Claude プラットフォームの全機能とドメイン知識を組み合わせたサービスを提供する。

実際の顧客成果として、保険引受サイクルが10週→10日、想定の4倍規模の COBOL コードベースのモダナイゼーションが予算内・スケジュール内、停滞していた HR プログラムが稼働プロトタイプ1週間・本番アプリ2ヶ月未満で復旧、セキュリティインシデント対応が数時間→数分などが報告されている。全体では最大70%のデリバリー改善を顧客が体感しているという。

### Anthropic: Claude Opus 4.7 が Fast Mode に対応 — 最大2.5倍高速、価格は標準の6倍 (May 13-14)

Anthropic が Claude Opus 4.7 を Fast Mode (研究プレビュー) に対応させた。May 14 から Claude Code の `/fast` コマンドは明示的に設定を変更していない限り、デフォルトで Opus 4.7 を使用するように切り替わった。Fast Mode は最大2.5倍高速なトークン生成を実現するが、料金は標準の6倍 (入力 $30 / 出力 $150 per million tokens)。モデルの知能・品質・コンテキスト窓は標準版と同一で、API ヘッダー `fast-mode-2026-02-01` で `speed: "fast"` を指定してアクセスする。Anthropic API・Claude Code・Cursor・Windsurf・v0・Warp で利用可能。

- 参考: [Claude Opus 4.7 Fast Mode: 2.5x Faster, 6x More Expensive](https://www.buildfastwithai.com/blogs/claude-opus-4-7-fast-mode-guide) (Build Fast With AI)

### <a id="openai-codex-mobile"></a>OpenAI: Codex が ChatGPT モバイルアプリに対応 — iOS/Android から AI コーディングエージェントをリモート制御 (May 14)

OpenAI が ChatGPT モバイルアプリ (iOS/Android) への Codex 統合プレビューを公開した。週次アクティブユーザー400万人に達した Codex コーディングエージェントを、スマートフォンからリモート制御できるようになる。

「スマートフォンが、ノート PC 上で稼働する Codex のリモコンになる」設計で、ユーザーはアクティブなタスクスレッドを切り替えながら、Codex が生成したファイル差分・テスト結果・ターミナル出力・スクリーンショットをリアルタイムで確認し、コマンドを承認したり新タスクを起動したりできる。セキュリティ面では、ファイル・認証情報・パーミッションは Codex が稼働するマシン上にとどまり、スマートフォンには転送されない。ユースケースとして「通勤中にバグ調査を依頼し判断を承認」「会議前にカスタマーサポートの状況を Codex にまとめさせる」などが例示されている。

同時に **Remote SSH が正式 GA** となった。Codex デスクトップアプリが既存の SSH 設定からリモートホストを自動検出し、企業の開発環境 (依存関係・認証情報・セキュリティポリシー・計算資源) に接続したまま Codex スレッドを実行できる。現在は macOS のみ対応で、Windows 版は近日予定。全 ChatGPT プラン (Free・Go 含む) に順次展開中。

- 元記事: [Work with Codex from anywhere](https://openai.com/index/work-with-codex-from-anywhere/) (OpenAI, May 14)
- 参考: [OpenAI says Codex is coming to your phone](https://techcrunch.com/2026/05/14/openai-says-codex-is-coming-to-your-phone/) (TechCrunch, May 14)
