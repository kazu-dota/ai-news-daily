### <a id="xai-grok-build"></a>xAI (SpaceXAI): Grok Build — 初の AI コーディングエージェント (May 14〜17)

xAI (現 SpaceXAI) が初の AI コーディングエージェント「Grok Build」を5月14〜17日にかけてリリースした。Anthropic の Claude Code や OpenAI Codex などが先行するコーディングエージェント市場への参入となる。

Grok Build はターミナルネイティブな CLI エージェントで、自然言語によるプロジェクト計画・ファイル編集・シェルコマンド実行・アプリ完全構築を自律的に行う。基盤モデルは Grok 4.3 beta で、200万トークンコンテキスト窓と **最大8並列のサブエージェント (Heavy アーキテクチャ)** を特徴とする。VS Code との連携も備える。プランに着手する前に必ずユーザー承認を求める「プランモード」でリスクを軽減する設計。

料金は通常 $299/月の SuperHeavy プランに含まれるが、早期採用向けに6ヶ月間 **$99/月 (67% オフ)** の導入割引を展開し、Claude Code ユーザーの乗り換えを狙っている。Elon Musk 自身が5月14日に X で公開ベータテスターを募集した。
