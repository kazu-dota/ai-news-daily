### <a id="anthropic-karpathy"></a>Anthropic: Andrej Karpathy が事前学習チームに参加 (May 19)

OpenAI 共同創業者で Tesla の FSD/Autopilot 責任者として知られる Andrej Karpathy が、Anthropic に入社したことが明らかになった。Karpathy 自身が X (旧 Twitter) で「Anthropic に入社した。LLM フロンティアの次の数年間は特別に重要な時期になると考えている。R&D に戻れることをとても楽しみにしている」と発表した。

Anthropic の説明によると、Karpathy は事前学習チームのリード Nick Joseph のもとに配属され、**Claude を使って pre-training 研究を加速させる専門チームを新設**する予定。pre-training は Claude の核心的な知識と能力を与える大規模訓練フェーズであり、Karpathy の深層学習・コンピュータビジョン・スケール訓練に関する深い知見をここに集中させる意図がある。2024年に Eureka Labs (教育特化スタートアップ) を創業した後、約2年で大規模な組織に戻る形となった。

### <a id="anthropic-microsoft-maia"></a>Anthropic: Microsoft Maia 200 チップ採用に向けた初期交渉を実施中 (May 21)

Bloomberg / CNBC が5月21日に報じたところによると、Anthropic は Microsoft のカスタム AI チップ「Maia 200」を搭載したサーバーの借用に向けた初期交渉を行っている (契約は未締結)。

Maia 200 は Microsoft が開発した自社シリコンで、Satya Nadella CEO は4月の決算会見で「最新の市場向け GPU と比較してトークンコストが30%以上向上する」と説明している。現時点では Azure の顧客向けには一般提供されていないが、Anthropic との契約が成立すれば Maia の初の大口外部顧客となり、Microsoft の自社製 AI シリコン戦略に大きな弾みがつく。

Anthropic にとっては、4月に締結した AWS Trainium との10年契約 ($100B 超) と、5月に発表した xAI/SpaceX Colossus 1 との月額 $1.25B の契約 (5/21 既報) に続く、第3のコンピュート調達源の多様化となる。Dario Amodei CEO は最近のインタビューでコンピュートの不足を課題として挙げており、複数社からの調達で供給リスクを低減する戦略とみられる。

### <a id="openai-ads-manager"></a>OpenAI: ChatGPT 広告の自社配信プラットフォーム「Ads Manager」を公開 (May 21)

OpenAI が ChatGPT 向け広告のセルフサービス型配信プラットフォーム「Ads Manager」(ベータ) を一般公開した。広告主は CPC (クリック課金) 入札設定・クリエイティブ管理・パフォーマンス計測を独自のダッシュボード上から直接操作できる。Dentsu・Omnicom・Publicis・WPP などエージェンシーパートナー、Adobe・Criteo・StackAdapt などテクノロジーパートナーとの連携も拡大している。

OpenAI は今年の広告収入目標として $2.5B (約360億円) を掲げ、2030年までに年間 $100B の広告収入を目指すとされる。広告は Free・Go プランの成人ログインユーザーにのみ表示され、有料プランには表示されない設計を維持する。

- 元記事: [New ways to buy ChatGPT ads — OpenAI](https://openai.com/index/new-ways-to-buy-chatgpt-ads/)

### <a id="trump-ai-eo"></a>ガバナンス: Trump 大統領が AI 大統領令の署名を直前でキャンセル (May 21)

トランプ大統領は5月21日 (木)、当日午後に予定していた AI に関する大統領令の署名式を突如キャンセルした。Oval Office でのコメントで「内容のいくつかの点が気に入らなかった」と述べ、具体的には「中国との AI 競争を阻害するようなことはしたくない」と発言した。
