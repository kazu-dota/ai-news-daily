### <a id="microsoft-project-polaris"></a>Microsoft: 自社製コーディング AI「Project Polaris」で GitHub Copilot を刷新 — 2026年8月 GA・IP 補償付き (Build 2026 前日)

Microsoft Build 2026 (6月2〜3日、サンフランシスコ Fort Mason Center) 開幕前日、複数のメディアが Microsoft 独自開発のコーディングモデル群 **「Project Polaris」** の概要を報じた。コーディング・トランスクリプション・推論・音声・画像など複数のタスク特化モデルを含む製品群で、GitHub Copilot を OpenAI 製モデル依存から脱却させることを狙いとしている。一般提供 (GA) の目標は **2026年8月** とされる。

大きな特徴のひとつが **Code Content Guarantee** で、許諾済みデータのみで訓練したことを保証し、IP (知的財産) 侵害クレームに対する顧客補償を明記している。Build 2026 ではマルチモーダルコーディング能力のプレビューも行われる見通しで、タブレットに手描きした UI スケッチから XAML や C# コードを生成するデモが想定されている。GitHub Copilot の新プラン体系 (Starter 無料・Pro・Enterprise) もあわせて発表される見込みだ。

### <a id="xai-grok-build-01"></a>xAI: アジェンティックコーディング特化モデル「Grok Build 0.1」を API 公開ベータで提供開始 (May 27–29)

xAI は自律コーディングタスクに特化した **「Grok Build 0.1」** を API 公開ベータとして提供開始した。コードベース全体を対象とした自律的なリファクタリング・デバッグ・ツール呼び出しに最適化されており、**256,000 トークン** のコンテキストウィンドウはミドルサイズのプロジェクト全体をメモリに保持できる規模だ。推論速度は **100+ tokens/秒** で、価格は入力 $1/M・出力 $2/M トークンと主要競合比で低廉に設定されている。

テキストと画像の双方を入力として受け付けるため、UI モックアップやエラースクリーンショットをそのまま渡して処理させることも可能。xAI はタスク完了まで継続して実行し続けるエージェントループへの最適化を設計の中心に据えたと説明している。
